# VibeMeet - Video Conferencing Application

## Project Overview
VibeMeet is a web-based video conferencing application that allows users to create and join online meetings with real-time audio and video communication.

## Original Project Acknowledgement
This project is based on the original classVideoCaller project by Sarvani.

Original Repository: https://github.com/sarvani134/classVideoCaller

Modifications and DevOps implementation are carried out for academic purposes.

## Technologies Used
- Frontend: React.js, Vite
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: Auth0
- Real-time Communication: Socket.IO and WebRTC

## DevOps Tools
- Git and GitHub
- Jenkins
- Docker
- Docker Compose
- Kubernetes

## DevOps Workflow
GitHub -> Jenkins -> Docker -> Kubernetes

## Project Purpose
The project is used for academic learning and practical implementation of DevOps concepts, including source code management, continuous integration, containerization and container orchestration.
